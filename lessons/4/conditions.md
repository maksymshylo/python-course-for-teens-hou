# 🛤️ Розгалуження та керування потоком у Python

У звичайному стані код виконується лінійно — рядок за рядком, зверху вниз. Але в реальному житті ми постійно ухвалюємо 
рішення залежно від обставин.

**Аналогія:** У твоєму розкладі о 18:00 стоїть похід у басейн. Але тобі надходить інформація, що воду злили. Логічно 
скасувати плавання й зайнятися чимось іншим. У програмуванні для таких рішень використовуються конструкції розгалуження.

---

## Базові конструкції (`if`, `else`, `elif`)

### 1. Одинарна умова `if`

Код всередині блоку `if` виконається лише тоді, коли вираз після нього є істинним (`True`).

```python
a = 4
if a < 10:
    print("Умова виконалась!")  # Обов'язковий відступ 4 пробіли!

```

### 2. Альтернатива `if - else`

Коли потрібно чітко розділити світ на "план А" та "план Б". Якщо умова хибна, автоматично спрацює блок `else`.

```python
a = 1
if a > 2:
    print("План А")
else:
    print("План Б")

```

### 3. Множинний вибір `if – elif – else`

Коли альтернатив більше ніж дві, використовується `elif` (*else if*). Python перевіряє їх по черзі зверху вниз до першого збігу.

```python
d = int(input("Уведіть число: "))

if d < 0:
    print("Від'ємне")
elif d == 0:
    print("Нуль")
else:
    print("Додатнє")

```

## Професійний синтаксис (Truthy/Falsy та Тернарники)

### 1. Концепція Truthy та Falsy (Що Python вважає істиною)

Тобі не обов'язково писати `if len(my_list) > 0:`. Усередині `if` Python автоматично викликає приховану функцію `bool()`. 
Всі об'єкти в мові діляться на два табори:

* 🚫 **Falsy (прирівнюються до брехні):** `None`, `False`, числові нулі (`0`, `0.0`), порожні рядки та колекції 
  (`""`, `[]`, `()`, `{}`, `set()`).
* **Truthy (прирівнюються до істини):** Усе інше (навіть рядок з одним пробілом `" "` або список з нулем `[0]`).

```python
# Поганий тон (код новачка):
users = []
if len(users) == 0:
    print("Список порожній")

# Чистий Python-style (Pythonic code):
if not users:  
    print("Список порожній!")

```

### 2. Тернарний оператор (Умова в один рядок)

Якщо потрібно просто записати у змінну одне з двох значень залежно від умови, розгортати `if-else` на 4 рядки не варто.

**Синтаксис:** `змінна = значення_якщо_True if умова else значення_якщо_False`

```python
a = 17
# Запис в один рядок
is_adult = True if a >= 18 else False

```

## Оптимізація та Логічні оператори (`and`, `or`, `not`)

Коли умови стають складними, ми об'єднуємо їх за допомогою логічних операторів. Тут вмикається прихована магія Python — 
**Логіка короткого замикання (Short-Circuit Evaluation)**. Інтерпретатор не обчислює умову до кінця, якщо результат уже 
очевидний.

### 🔹 Оператор `and` (Шукає першу брехню)

Якщо ліва частина умови `and` є хибною (`False`), то права частина **взагалі не обчислюється**, бо весь вираз уже точно
буде `False`.

```python
def check_heavy_database():
    print("📡 Робимо важкий запит до бази даних...")
    return True

is_admin = False

# Завдяки короткому замиканню, важка функція НАВІТЬ НЕ ЗАПУСТИТЬСЯ!
if is_admin and check_heavy_database():
    print("Доступ дозволено")

```

### 🔸 Оператор `or` (Шукає першу істину)

Якщо ліва частина умови `or` є істинною (`True`), права частина повністю ігнорується, бо вираз уже 100% буде `True`.

> ⚙️ **Правило оптимізації:** Завжди став на перше місце у складних умовах найпростіші перевірки (булеві змінні, 
> порівняння чисел), а важкі функції або запити в інтернет — на останнє місце.

## Structural Pattern Matching

Починаючи з версії Python 3.10, у мову додали інструмент **`match-case`**. Це не просто аналог `switch-case` з інших мов, 
це потужний інструмент, який вміє аналізувати структуру даних і розпаковувати її «на льоту».

### 1. Просте порівняння значень (Заміна великих драбинок `elif`)

```python
status_code = 404

match status_code:
    case 200:
        print("🟢 Все OK")
    case 400 | 404:  # Вертикальна риска означає "або"
        print("🔴 Помилка клієнта")
    case 500:
        print("🔥 Помилка сервера")
    case _:  # Символ підкреслення — це аналог else (дефолтний варіант)
        print("🛸 Невідомий код")

```

### 2. Робота зі структурами даних (Паттерн-матчінг)

`match-case` може перевіряти, що саме прилетіло в програму (список, кортеж тощо), аналізувати кількість елементів і 
автоматично розкладати їх по змінних.

```python
# Уяви, що це команда, яка прилітає від користувача в чат-бота
command = ["download", "music.mp3"]

match command:
    case ["quit"]:
        print("Завершення роботи")
        
    case ["download", filename]:  
        # Python сам зрозумів, що другий елемент списку треба записати у змінну filename!
        print(f"Завантажуємо файл: {filename}")
        
    case ["move", *coordinates]:  
        # Зірочка збере всі інші елементи (скільки б їх не було) у список coordinates
        print(f"Рух за координатами: {coordinates}")
        
    case _:
        print("⚠️ Невідома команда")

```

## Важливо

1. **Не порівнюй булеві змінні прямо:** Замість `if var == True:` пиши просто `if var:`.
2. **Уникай "спагеті-коду":** Якщо всередині `if` стоїть ще один `if`, а в ньому ще один (глибше 3-х рівнів відступів) — 
   твій код стає нечитабельним. Розбивай логіку логічними операторами (`and`, `or`) або винось перевірки в окремі функції.
3. **Використовуй Guard Clauses (Захисні умови):** Замість того, щоб огортати весь основний код у гігантський `if`, 
   краще спочатку перевірити помилку і вийти з функції через `return`.
