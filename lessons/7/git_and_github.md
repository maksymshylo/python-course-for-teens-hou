Якщо ти цікавишся технологіями, програмуванням або просто хочеш зрозуміти, як 
розробники створюють круті ігри та додатки, ви точно чули слова **Git** та **GitHub**.

Розберімось, що це таке.

---

## 🛠 Що таке Git? (Твоя машина часу)

Уяви, що ти пишеш реферат або код для гри. 
Ти зробив якусь частину і зберіг файл як `game_v1.py`. 
Потім додав нову фічу(feature) і зберіг як `game_v2_final.py`. 
Потім усе зламалося, і з'явився файл `game_v3_real_final_top.py`.

**Git** — це **система контролю версій**. 
Це спеціальна програма, яка працює на твоєму комп'ютері та діє як машина часу для твого коду.

* Вона запам'ятовує кожне збереження(save) (у Git це називається **комміт** / commit).
* Якщо ти написав код, і все зламалося, ти можеш в один клік повернутися до моменту, коли все працювало.
* Ти можеш створювати **гілки** (branches) — наприклад, щоб протестувати нову суперздібність для персонажа, 
  не ламаючи основну гру.

---

## 🐙 Що таке GitHub? (Соцмережа для коду)

Якщо Git — це програма на твоєму комп'ютері, то **GitHub** — це сайт у мережі (хмара). Це як Instagram або TikTok, 
але замість фото чи відео люди викладають туди свій код.

На GitHub ти можеш:

* Зберігати свій код у безпеці (якщо згорить комп, код залишиться в хмарі).
* Показувати свої проєкти іншим (наприклад, майбутньому роботодавцю або друзям).
* **Працювати в команді:** ти можеш писати код разом із друзями з іншого міста чи країни над одним проєктом одночасно.

> 💡 **Проста аналогія:** 
> **Git** — це як гра Minecraft на твоєму комп'ютері, де ти будуєш світ.
> **GitHub** — це сервер Minecraft в інтернеті, куди ти викладаєш свій світ, щоб грати 
разом із друзями.

## 🗺 Візуалізація: як це працює

Ось текстова схема того, як твій код подорожує від твого комп'ютера на GitHub і як працюють «гілки» розробки:

```text
 [ Твій комп'ютер ]                       [ Хмара: GitHub ]
 ------------------                       -----------------
 
 Крок 1: Пишеш код 
       │
       ▼
 Крок 2: Робиш save (Commit)
       │
       ▼
 Крок 3: Відправляєш в хмару (Push) ────────> [ Твій репозиторій ]
                                                    │
                                                    ▼
                                       (Код тепер бачать усі!)

```

А ось так виглядає **робота з гілками** 
(коли ти хочеш додати нову feature, не зламавши головний код):

```text
Головна гілка (Main): ──[Старт]───[Сейв 1]─────────────────[Сейв 3 (Реліз)]──>
                                    │                             ▲
                                    │ (Створив гілку для фічі)    │ (Злив докупи)
                                    ▼                             │
Гілка з фічею (Feature):            └───[Пишеш нову суперсилу]────┘

```

Давай розберемо **головні команди**

## 🧙‍♂️ Магічні заклинання: Основні команди Git

Усі програмісти керують Git не мишкою, а через чорне вікно термінала (консолі), 
вводячи спеціальні текстові команди.

* `git init` — **«Створити магію тут»**. Ця команда каже Git: *"Починай стежити за цією папкою з кодом"*.
* `git add .` — **«Завантажити речі в багажник»**. Ти вибираєш усі змінені файли та готуєш їх до збереження.
* `git commit -m "Додав суперстрибок"` — **«Зробити сейв»**. Ти фіксуєш зміни й обов'язково пишеш коментар у лапках (коментар має пояснювати, що саме ти змінив, щоб не заплутатися через місяць).
* `git push` — **«Відправити в космос»**. Ця команда бере твої локальні «сейви» з комп'ютера і завантажує їх на сайт GitHub.
* `git pull` — **«Забрати оновлення»**. Якщо твій друг оновив код у хмарі, ця команда завантажить його зміни на твій комп'ютер.

## 📖 Словничок хакера (Терміни, які треба знати)

Коли ти почнеш спілкуватися з іншими розробниками, ти почуєш багато дивного сленгу.

| Термін | Що це означає на практиці? |
| --- | --- |
| **Репозиторій (Репо)** | Просто папка твого проєкту, яка перебуває під контролем Git або лежить на GitHub. |
| **Форк (Fork)** | Копіювання чужого проєкту собі в профіль в один клік. Наче ти скопіював чиюсь карту в Minecraft, щоб перебудувати її по-своєму. |
| **Клон (Clone)** | Завантаження проєкту з GitHub на свій комп'ютер для роботи. |
| **Пулл Реквест (Pull Request / PR)** | Пропозиція змін. Ти покращив чийсь код, натиснув кнопку і кажеш автору: *"Привіт! Я виправив баг у твоїй грі, подивись і додай це в основну версію"*. |

Уяви, що ти хочеш додати нову функцію в Discord-бота, якого написав твій друг:

Твій комп'ютер                   Твій акаунт GitHub             Проєкт твого друга

1. Клонуєш проєкт друзів 
   <─────────────────────────────────────────────────────────── [Оригінальний код]

          │

                                         │
                                         ▼
                               [Друг перевіряє код]
                                         │
                               5. Merge (Злиття) 🎉 ──────────> [Бот оновився для всіх!]

## ✨ Чому GitHub — це круто особисто для тебе?

1. **Open Source (Відкритий код):** Величезна кількість крутих речей — від модів на Minecraft та читів до цілих операційних систем — лежать на GitHub безкоштовно. Ти можеш відкрити код улюбленого Discord-бота, подивитися, як він влаштований, і навчитися писати так само.
2. **Прокачка профілю:** Твоя сторінка на GitHub — це твоє справжнє резюме. Замість слів *"я вмію кодити"*, ти просто кидаєш лінк, де видно твої реальні проєкти. До речі, свою сторінку можна кастомізувати за допомогою Markdown: додавати туди красиві банери, гіфки, статистику та віджети з треками зі Spotify.
3. **Зелений календар (Вайб продуктивності):** У профілі кожного юзера є сітка внесків (Contributions). Щоразу, коли ти зберігаєш код, квадратик дня стає зеленим. Що більше ти кодиш, то зеленіший твій профіль. Для багатьох це стає прикольною грою — «зафарбуй весь календар».

## Практика

### 🚀 Крок 1: Створюємо базу (Акаунт)

Якщо в тебе ще немає акаунту, переходь на [github.com](https://github.com/) і реєструйся.

> 💡 **Порада щодо нікнейму:** Вибирай нік з розумом (наприклад, `alex-dev` або `kate-codes`), бо ти будеш кидати це посилання друзям чи навіть майбутньому роботодавцю. Ніяких `p0w3r_k1ll3r_2012`.

---

### 🎁 Крок 2: Активуємо пасхалку від GitHub

Коли ти залогінишся, ми створимо особливу папку (репозиторій).

1. У правому верхньому кутку натисни на плюс **`+`** і вибери **New repository** (Новий репозиторій).
2. **У полі Repository name напиши СВІЙ нікнейм.** Один в один, як твій логін.
3. Якщо ти все зробив правильно, GitHub покаже секретне повідомлення: *«You found a secret! ...»* (Ти знайшов секрет!).
4. Постав галочку на **Public** (щоб усі бачили твоє творіння).
5. Обов'язково постав галочку біля **Add a README file**.

Натискай зелену кнопку **Create repository** в самому низу.

---

### ✍️ Крок 3: Твій перший у житті комміт (save)

Тепер перед тобою файл `README.md`. Це головна сторінка твого профілю. Давай відредагуємо її прямо в браузері!

1. Знайди іконку **олівця** ✏️ у верхньому правому кутку блоку з текстом і натисни її.
2. Тепер ти в режимі редагування. Ти побачиш стандартний текст. Видали його і напиши щось про себе, використовуючи вже знайомий тобі Markdown. Наприклад:

```markdown
# Привіт, я [Твоє Ім'я]! 👋

- 🚀 Зараз я вивчаю Git та GitHub!
- 💻 Мій стек: Python, HTML (або те, що тобі подобається)
- 🎮 У вільний час я граю в... або створюю роботів

```

3. А тепер робимо той самий **комміт**! Гортай сторінку трохи вниз або шукай кнопку **Commit changes...** (Зберегти зміни) у верхньому правому кутку.
4. У віконці, що з'явиться, напиши назву свого сейву, наприклад: `Додав інфо про себе`.
5. Тисни зелену кнопку **Commit changes**.

---

### 🎉 Крок 4: Дивись на результат!

Тепер натисни на свій аватар у верхньому правому кутку і вибери **Your profile** (Твій профіль).

```text
+-------------------------------------------------------------+
|  [ Фото ]  Ім'я Користувача                                 |
|            @твій_нікнейм                                    |
|                                                             |
|  +-------------------------------------------------------+  |
|  | 👋 ПРИВІТ, Я ТВОЄ ІМ'Я!                               |  |
|  | 🚀 Зараз я вивчаю Git та GitHub!                      |  |
|  | 💻 Мій стек: Python...                                |  |
|  +-------------------------------------------------------+  |
|                                                             |
|  📌 Популярні репозиторії               🟩🟩⬜🟩  Календар |
+-------------------------------------------------------------+

```

Ти щойно створив репозиторій, відредагував код і зробив свій перший комміт.
