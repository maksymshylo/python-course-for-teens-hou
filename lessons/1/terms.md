Шпаргалка з термінів Python (UA / EN)

| Українська              | Англійська (English) | Приклад у Python                    | Що це простими словами?                                                            |
|:------------------------|:---------------------|:------------------------------------|:-----------------------------------------------------------------------------------|
| **Код**                 | Code                 | `print("Hello!")`                   | Текст програми.                                                                    |
| **Змінна**              | Variable             | `score = 10`                        | «Коробка» для зберігання даних під власною назвою.                                 |
| **Тип даних**           | Data type            | `int`, `str`, `bool`                | Яка саме інформація лежить у змінній.                                              |
| **Рядок (текст)**       | String (`str`)       | `"Python"`, `"Game Over"`           | Будь-який текст у лапках.                                                          |
| **Ціле число**          | Integer (`int`)      | `5`, `0`, `-12`                     | Числа без крапки (цілі).                                                           |
| **Число з комою**       | Float (`float`)      | `3.14`, `9.99`                      | Дробні числа (у Python пишуться через крапку).                                     |
| **Булеве значення**     | Boolean (`bool`)     | `True` або `False`                  | Логічний тип: тільки Правда або Брехня.                                            |
| **Умова**               | Condition            | `score > 5`                         | Перевірка, яка повертає `True` або `False`.                                        |
| **Розгалуження**        | If-statement         | `if score > 5:`                     | Команда, яка спрямовує код різними шляхами залежно від умови.                      |
| **Цикл**                | Loop                 | `for i in range(3):`                | Повторення однієї дії кілька разів.                                                |
| **Список**              | List                 | `items = ["sword", "shield"]`       | Набір елементів, записаних по порядку в одну змінну.                               |
| **Індекс**              | Index                | `items[0]` *(нуль — це індекс)*     | Порядковий номер елемента в списку (**рахунок завжди починається з 0**).           |
| **Метод**               | Method               | `text.upper()`, `items.append()`    | Спеціальна функція, яка прив'язана до об'єкта і щось із ним робить.                |
| **Конкатенація**        | Concatenation        | `"Py" + "thon"` *(= "Python")*      | Склеювання кількох рядків (тексту) в один.                                         |
| **F-рядок**             | F-string             | `f"Вам {age} років"`                | Зручний спосіб вставляти змінні прямо всередину тексту.                            |
| **Порівняння**          | Comparison           | `==` (рівно), `!=` (не дорівнює)    | Оператори для порівняння значень між собою.                                        |
| **Логічні оператори**   | Logical operators    | `and`, `or`, `not`                  | Спосіб об'єднати кілька умов в одну (наприклад: якщо є ключ **і** відкриті двері). |
| **Інкремент**           | Increment            | `score += 1`                        | Збільшення значення змінної (наприклад, коли гравець отримує бал).                 |
| **Функція**             | Function             | `def super_jump():`                 | Міні-команда, яку можна викликати багато разів у різних місцях.                    |
| **Аргумент**            | Argument / Parameter | `print("Hi")` *("Hi" — аргумент)*   | Те, що ми передаємо всередину функції для її роботи.                               |
| **Повернення значення** | Return               | `return result`                     | Команда, яка змушує функцію «віддати» результат роботи назад у код.                |
| **Глобальна змінна**    | Global variable      | *Створена на початку коду*          | Змінна, яку видно всюди в програмі (всередині будь-яких функцій).                  |
| **Локальна змінна**     | Local variable       | *Створена всередині функції*        | Змінна, яка живе і працює тільки всередині своєї функції.                          |
| **Введення даних**      | Input                | `name = input()`                    | Те, що користувач пише з клавіатури в програму.                                    |
| **Виведення даних**     | Output               | `print("You win!")`                 | Те, що програма виводить на екран користувачу.                                     |
| **Відступ**             | Indentation          | *4 пробіли на початку рядка*        | Пробіли на початку рядка, критично важливі для структури Python.                   |
| **Помилка (баг)**       | Bug                  | `prnt("Hello")` *(помилка назви)*   | Помилка в коді, через яку все ламається або йде не за планом.                      |
| **Пошук помилок**       | Debugging            | *Читання помилки в консолі*         | Процес знаходження та виправлення багів.                                           |
| **Синтаксис**           | Syntax               | *Двокрапка `:` після `if` чи `def`* | Правила «граматики» мови програмування.                                            |
| **Коментар**            | Comment              | `# Це код для стрибка`              | Текст для людини в коді, який комп'ютер повністю ігнорує.                          |
| **Модуль / Бібліотека** | Module / Library     | `import random`, `import pygame`    | Готовий код інших розробників для додавання крутих фішок (графіка, рандом).        |
| **Нескінченний цикл**   | Infinite loop        | `while True:`                       | Цикл, який ніколи не зупиняється сам (основа ігрових рушіїв).                      |
| **Ключове слово**       | Keyword              | `if`, `else`, `def`, `while`        | Слова, зарезервовані в Python. Їх не можна назвати змінними.                       |
| **Округлення**          | Rounding             | `round(3.6)` *(= 4)*                | Перетворення числа з комою на ціле число за правилами математики.                  |
| **Остача від ділення**  | Modulo               | `10 % 3` *(= 1)*                    | Оператор, що показує остачу (використовують для перевірки парності чисел).         |
| **Середовище**          | IDE                  | *Thonny, PyCharm, VS Code*          | Програма, в якій ми пишемо код.                                                    |
