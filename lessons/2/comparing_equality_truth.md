# ⚖️ Порівняння, рівність та істина в Python

Будь-які об'єкти мови Python підтримують операції порівняння: перевірка на рівність, відносна величина тощо. 

Головна особливість Python — при порівнянні складних вкладених об'єктів інтерпретатор автоматично виконує обхід структури даних, щоб застосувати операції порівняння **рекурсивно**, зліва направо і настільки глибоко, наскільки це необхідно. Перша знайдена відмінність визначає результат.

---

## 🆚 Різниця між `==` та `is`

Через природу посилань на об'єкти в Python існує два абсолютно різних способи перевірки:

* **Оператор `==` (Рівність значень):** Перевіряє, чи однаковий вміст мають об'єкти. Він рекурсивно заглядає всередину списків, словників та інших контейнерів.
* **Оператор `is` (Ідентичність об'єктів):** Перевіряє, чи вказують дві змінні на **один і той самий об'єкт у пам'яті** (тобто порівнює їхні ID/адреси через функцію `id()`).

### 🧪 Приклад 1: Списки з однаковим вмістом
Створимо два різні списки з однаковими значеннями:

```python
L1 = [1, ['a', 3]]  
L2 = [1, ['a', 3]]

print(L1 == L2)  # True  -> Значення всередині абсолютно однакові
print(L1 is L2)  # False -> Це два різних "вагони" в різних місцях пам'яті
```

В даному випадку `L1` і `L2` пройшли перевірку на рівність, але провалили перевірку на ідентичність, бо це два окремі об'єкти.

## 🏎️ Оптимізація пам'яті (Інтернування)

У Python є приховані механізми оптимізації, які можуть збити з пантелику початківців. Подивіться, що відбувається при порівнянні коротких рядків:

```python
S1 = 'Spam'
S2 = 'Spam'

print(S1 == S2)  # True
print(S1 is S2)  # True ! (Хоча ми чекали False)

```

### 🧠 Чому `is` повернув `True`?

З метою економії оперативної пам'яті та прискорення роботи інтерпретатор Python використовує **інтернування (кешування) коротких рядків**. Якщо рядок короткий і не містить спецсимволів, Python не створює новий об'єкт, а просто дає змінній `S2` посилання на вже існуючий у пам'яті рядок `'Spam'`.

Оскільки рядки є **незмінними (`immutable`)**, цей трюк абсолютно безпечний: ти не можеш випадково змінити цей рядок для обох змінних одночасно.

Щоб побачити стандартну поведінку, потрібно використати довший рядок (або рядок із пробілами), який Python вже не буде автоматично кешувати:

```python
S1 = 'a longer string'
S2 = 'a longer string'

print(S1 == S2)  # True  -> Значення однакові
print(S1 is S2)  # False -> Тепер це дійсно два різних об'єкти в пам'яті

```

## 🛠️ Інші важливі "пастки" оптимізації

### 1. Кешування малих чисел (Small Integers)

Python автоматично кешує всі цілі числа в діапазоні **від -5 до 256**. Вони створюються один раз при запуску Python і постійно перевикористовуються.

```python
# Випадок 1
x = 250
y = 250
print(x is y)  # True (В межах кешу)

# Випадок 2
a = 300
b = 300
print(a is b)  # False (Вийшли за межі кешу, це два різних об'єкти)

```
Випадок 2 дійсно буде `False` якщо код запускається в режимі термінала, а не скрпиті (як файл).


### 2. Коли `is` ДІЙСНО потрібен?

У 99% випадків для порівняння даних потрібно використовувати оператор `==`. Проте є один класичний виняток, де використання `is` є стандартом коду (PEP 8) — це перевірка на порожнечу `None`.

Об'єкт `None` в Python завжди існує в єдиному екземплярі, тому його ідентичність перевіряють через `is`:

```python
user_avatar = None

if user_avatar is None:
    print("У користувача немає аватара")

```

## 📋 Коротке резюме

* Хочеш порівняти текст, числа, списки чи логіку? ➡️ Пиши **`==`**.
* Хочеш перевірити, чи це буквально той самий об'єкт (або перевіряєш `None`)? ➡️ Пиши **`is`**.
