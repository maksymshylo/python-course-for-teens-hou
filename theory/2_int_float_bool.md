# 🧱 Базові типи даних у Python: `int`, `float` та `bool`

У Python кожне значення має свій тип. Три найважливіші прості типи, на яких будуються всі обчислення та логіка — це **цілі числа (`int`)**, **дійсні числа (`float`)** та **логічні значення (`bool`)**.

---

## 1. Цілі числа — `int` (Integer)

Тип `int` представляє будь-які цілі числа (додатні, від'ємні або нуль) без десяткової частини.

* **Приклади:** `4`, `0`, `-15`, `100000`.
* **Особливість у Python:** На відміну від багатьох інших мов програмування, у Python тип `int` має "необмежену точність". Тобто ви можете працювати з надзвичайно великими числами (наприклад, мільярд у сотому степені), і комп'ютер не видасть помилки переповнення пам'яті.

```python
# Приклади роботи з int
age = 25
temperature = -5
stars_in_galaxy = 400000000000  # Python легко працює з великими числами

# Для зручності великі числа можна розділяти нижнім підкресленням
money = 1_000_000  # Те саме, що й 1000000. Python ігнорує "_"
print(money)  # Виведе: 1000000

```

---

## 2. Числа з плаваючою крапкою — `float` (Floating-point)

Тип `float` представляє дійсні числа, тобто числа, які мають дробову (десяткову) частину.

* **Приклади:** `3.14`, `-0.5`, `10.0`.
* **Важливо:** У програмуванні роздільником завжди є **крапка `.**`, а не кома. Число `10` — це `int`, але `10.0` — це вже `float`.
* **Прихована пастка:** Комп'ютери зберігають дробові числа у двійковій системі, через що деякі звичні нам десяткові дроби не можуть бути записані абсолютно точно.

```python
# Приклади роботи з float
pi = 3.14159
weight = 72.5

# Пастка округлення:
print(0.1 + 0.2)  # Виведе: 0.30000000000000004 через особливості двійкової арифметики!

# При діленні двох цілих чисел (int) ми ЗАВЖДИ отримуємо float
result = 10 / 2
print(result)  # Виведе: 5.0 (а не 5)

```

---

## 3. Логічний тип даних — `bool` (Boolean)

Тип `bool` містить лише два можливих значення: **`True` (Істина)** або **`False` (Хибність)**.

* **Важливо:** Писати ці слова потрібно обов'язково з **великої літери** (`True`, `False`). Маленькі літери `true`/`false` Python не зрозуміє і видасть помилку.
* Логічні значення зазвичай з'являються в програмі як результат роботи операторів порівняння (`>`, `<`, `==`).

```python
is_active = True
has_access = False

# Результат порівняння автоматично стає типом bool
is_greater = 5 > 3
print(is_greater)  # Виведе: True

```

## 4. Перетворення типів (Type Casting)

Часто виникає ситуація, коли один тип даних потрібно перетворити на інший. Для цього існують вбудовані функції, назви яких збігаються з назвами типів: `int()`, `float()`, `bool()`.

### Перетворення на `int` та `float`

```python
# Перетворення тексту на числа
string_num = "42"
num = int(string_num)     # Стає цілим числом 42
pi_num = float("3.14")    # Стає дробовим числом 3.14

# Округлення дробового числа до цілого
# Примітка: int() НЕ округлює за математичними правилами, він просто відкидає дробову частину!
print(int(5.99))  # Виведе: 5

```

### Особливості перетворення на логічний тип (`bool`)

Коли ми перетворюємо якесь значення на `bool()`, Python ділить усі значення у світі на "порожні/нульові" (вони перетворюються на `False`) та "наповнені" (вони перетворюються на `True`).

* **Що перетворюється на `False` (так звані Falsy значення):**
* Число нуль (`0` або `0.0`)
* Порожній рядок (`""`)
* Спеціальний тип відсутності значення (`None`)


* **Все інше перетворюється на `True`.**

```python
print(bool(100))    # True (число не нуль)
print(bool(-5))     # True (негативне число — це теж НЕ нуль!)
print(bool("Hi"))   # True (рядок має символи)

print(bool(0))      # False (нуль)
print(bool(""))     # False (порожній рядок)

```
