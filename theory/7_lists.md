# 📊 Списки в Python: Тип даних `list`

**Список (`list`)** — це впорядкована колекція елементів, яка дозволяє зберігати 
кілька значень (навіть різних типів) в одній змінній. Списки є **змінними (mutable)**, 
тобто ви можете додавати, видаляти або змінювати елементи після створення списку.

---

## 1. Створення списків

Список створюється за допомогою **квадратних дужок `[]**`, а елементи всередині розділяються комами.

```python
# Порожній список
empty_list = []

# Список чисел
numbers = [10, 20, 30, 40, 50]

# Список рядків
fruits = ["яблуко", "банан", "апельсин"]

# Списки можуть містити різні типи даних (навіть інші списки)
mixed_list = [42, "Привіт", True, 3.14, [1, 2, 3]]

```

---

Ось розширений варіант теорії, адаптований під англомовний контент вашого проєкту (тема бібліотеки/архіву) з детальним поясненням «розумних» зрізів (крок, розворот, негативні індекси та модифікація).

---

## 2. Індексація та зрізи списків

Кожен елемент списку має свій **індекс**, який вказує на його позицію. Індексація завжди починається з **0**. Також Python підтримує **негативну індексацію** — рахунок з кінця списку (останній елемент має індекс `-1`).

```python
library_preview = ["Python", 101, "Data", 102]

# Отримання елементів за індексом
print(library_preview[0])   # "Python" (перший елемент)
print(library_preview[-1])  # 102 (останній елемент з кінця)

# Зміна елемента за індексом
library_preview[2] = "SQL"  # Замінить "Data" на "SQL"
print(library_preview)       # ["Python", 101, "SQL", 102]

```

### ✂️ Розумні зрізи (Slicing) — Повний синтаксис `[start:stop:step]`

Зрізи дозволяють копіювати частину списку або ділити його на шматки, не змінюючи оригінал. Повна формула зрізу виглядає так: **`список[старт:стоп:крок]`**.

* **`start`** — індекс, з якого починається зріз (включається).
* **`stop`** — індекс, на якому зріз закінчується (**НЕ включається**).
* **`step`** — крок, з яким вибираються елементи (за замовчуванням дорівнює 1).

> 💡 **Правило пропусків:** Якщо не вказати `start`, Python почне з самого початку `0`. Якщо не вказати `stop`, зріз піде до самого кінця списку.

```python
archive = ["Python", 101, "Data", 102, "Algorithms", 103, "AI", 104]

# 1. Базовий зріз [старт:стоп]
# Беремо елементи з індексами 2, 3, 4 (індекс 5 не входить)
print(archive[2:5])       # ["Data", 102, "Algorithms"]

# 2. Зріз від початку до N елемента
print(archive[:2])        # ["Python", 101] (швидкий спосіб взяти перші два елементи)

# 3. Зріз від N елемента до самого кінця
print(archive[4:])        # ["Algorithms", 103, "AI", 104]

# 4. Негативні зрізи (хвіст списку)
print(archive[-2:])       # ["AI", 104] (швидкий спосіб отримати N останніх елементів)

# 5. Розумний зріз із кроком [::step]
# Забираємо лише назви книг (кожен другий елемент, починаючи з 0)
print(archive[::2])       # ["Python", "Data", "Algorithms", "AI"]

# Забираємо лише інвентарні коди (починаємо з 1-го індексу через один)
print(archive[1::2])      # [101, 102, 103, 104]

# 6. Розворот списку (Магія негативного кроку)
# Крок -1 змушує Python йти у зворотному напрямку
print(archive[::-1])      # [104, "AI", 103, "Algorithms", 102, "Data", 101, "Python"]

# 7. Повне копіювання списку
archive_copy = archive[:] # Створює чисту незалежну копію всього списку

```

### ⚠️ Трюк: Зміна списку через зрізи (Масове редагування)

Зрізи можна використовувати не тільки для читання, а й для заміни цілих блоків даних в один рядок:

```python
numbers = [10, 20, 30, 40, 50]
# Замінимо елементи з 1 по 3 індекси (тобто 20 та 30) новим списком
numbers[1:3] = [99, 99, 99]
print(numbers) # [10, 99, 99, 99, 40, 50]

```

## 3. Функція `len()` для списків

Функція `len()` (скорочення від *length* — довжина) є однією з найуживаніших вбудованих функцій. Вона повертає **кількість елементів** у списку.

```python
numbers = [10, 20, 30, 40, 50]

# Дізнаємося кількість елементів
count = len(numbers)
print(f"У списку є {count} елементів.") # Виведе: У списку є 5 елементів.

# Перевірка, чи список не порожній за допомогою len()
my_tasks = []
if len(my_tasks) == 0:
    print("У вас немає запланованих завдань!")

```

> 💡 **Нагадування:** Ми вже зустрічали `len()` раніше. Якщо застосувати `len()` до тексту (`str`), 
> вона поверне кількість символів у рядку. 
> Якщо до списку (`list`) — кількість елементів у списку.

---

## 4. Основні методи роботи зі списками

Оскільки списки динамічні, Python має багато зручних методів для керування ними:

```python
todo = ["купити каву"]

# 1. append(елемент) — додає елемент В КІНЕЦЬ списку
todo.append("почитати книгу")
todo.append("поприбирати")
print(todo)  # ["купити каву", "почитати книгу", "поприбирати"]

# 2. insert(індекс, елемент) — додає елемент у ВКАЗАНЕ МІСЦЕ, зсуваючи інші
todo.insert(1, "зателефонувати мамі")
print(todo)  # ["купити каву", "зателефонувати мамі", "почитати книгу", "поприбирати"]

# 3. remove(значення) — видаляє ПЕРШИЙ знайдений елемент із таким значенням
todo.remove("почитати книгу")
print(todo)  # ["купити каву", "зателефонувати мамі", "поприбирати"]

# 4. pop(індекс) — видаляє та ПОВЕРТАЄ елемент за індексом (якщо не вказати індекс — видалить останній)
deleted_item = todo.pop(0)
print(f"Видалено завдання: {deleted_item}") # "купити каву"
print(todo)  # ["зателефонувати мамі", "поприбирати"]

# 5. Сортування списку
digits = [5, 1, 9, 3]
digits.sort() # Сортує за зростанням
print(digits) # [1, 3, 5, 9]

```

## 🔍 Практичний приклад: Система керування кошиком покупця

Поєднаємо списки, функцію `len()`, додавання елементів та умовні оператори `if-else`:

```python
# Створюємо порожній кошик для покупок
cart = []

print("--- 🛒 Ваша інтернет-покупка ---")

# Додаємо товари в кошик
cart.append("Смартфон")
cart.append("Чохол для телефону")
cart.append("Навушники")

# Перевіряємо кількість товарів за допомогою len()
total_items = len(cart)
print(f"Ви додали до кошика стільки товарів: {total_items}")
print(f"Ваш поточний список: {cart}")

# Логіка знижки залежно від кількості товарів
if total_items >= 3:
    print("🎉 Вітаємо! Ви додали 3 або більше товарів і отримуєте безкоштовну доставку!")
else:
    print(f"Додайте ще {3 - total_items} товар(и), щоб отримати безкоштовну доставку.")

# Клієнт вирішив прибрати останній доданий товар (Навушники)
removed = cart.pop()
print(f"\n❌ Ви видалили з кошика: {removed}")
print(f"Нова кількість товарів: {len(cart)}")
print(f"Остаточний кошик: {cart}")

```
