# 🧵 Рядки в Python: Тип даних `str` (String)

Рядки в Python використовуються для роботи з текстовою інформацією. Рядок — це впорядкована послідовність символів (літер, цифр, розділових знаків чи пробілів).

---

## 1. Створення рядків

Рядки можна створювати за допомогою **одинарних (`'`)** або **подвійних (`"`)** лапок. Різниці між ними для Python немає, але важливо закривати рядок тими ж лапками, якими його відкрили.

```python
message1 = 'Привіт усім!'
message2 = "Python — це круто."

# Якщо всередині тексту є одинарна лапка, сам рядок краще взяти у подвійні:
quote = "It's a beautiful day" 

# Багаторядкові тексти (записуються в потрійних лапках)
long_text = """Цей рядок
може займати
кілька рядків у коді."""

```

---

## 2. Індексація та зрізи рядків (Slicing)

Кожен символ у рядку має свій порядковий номер — **індекс**.

* Індексація починається з **0** (для першого символу).
* Python також підтримує **негативну індексацію**: `-1` — це останній символ, `-2` — передостанній і так далі.

```python
word = "Python"

# Отримання окремого символу за індексом
print(word[0])   # 'P' (перший символ)
print(word[-1])  # 'n' (останній символ)

# Зрізи (Slicing) — отримання частини рядка за формулою [старт:стоп:крок]
# Важливо: символ на позиції 'стоп' не включається в результат!
print(word[0:4])   # 'Pyth' (символи з 0 по 3)
print(word[2:])    # 'thon' (від 2-го індексу і до кінця)
print(word[:3])    # 'Pyth' -> вибачте, 'Pyt' (з початку до 3-го, тобто 0, 1, 2)
print(word[::-1])  # 'nohtyP' (трюк для розгортання рядка задом наперед за допомогою кроку -1)

```

---

## 3. Операції з рядками

Рядки можна додавати (склеювати) та множити (дублювати).

```python
# Конкатенація (додавання)
first_name = "Тарас"
last_name = "Шевченко"
full_name = first_name + " " + last_name
print(full_name)  # Тарас Шевченко

# Мультиплікація (множення рядка на число)
line = "-" * 10
print(line)  # ----------

```

> ⚠️ **Рядки незмінні (Immutable):** Ви не можете змінити конкретний 
> символ у наявному рядку прямо. Команда `word[0] = "W"` викличе помилку. 
> Щоб змінити рядок, потрібно створити новий на його основі.

---

## 4. Корисні методи рядків

Методи — це спеціальні функції, які застосовуються безпосередньо до рядка через крапку. Вони повертають **новий** змінений рядок.

```python
text = "  Python є цікавим!  "

# 1. Зміна регістру
print(text.upper())  # "  ВИВЧЕННЯ PYTHON Є ЦІКАВИМ!  " (все великими)
print(text.lower())  # "  вивчення python є цікавим!  " (все маленькими)

# 2. Видалення зайвих пробілів на початку та в кінці
clean_text = text.strip()
print(clean_text)    # "Python є цікавим!"

# 3. Заміна частин тексту
new_text = clean_text.replace("цікавим", "легким")
print(new_text)      # "Python є легким!"

# 4. Перевірка вмісту рядка (повертає True або False)
print("Python".isalpha())  # True (чи складається тільки з літер)
print("12345".isdigit())   # True (чи складається тільки з цифр)

# 5. Довжина рядка (кількість символів разом із пробілами)
print(len("Привіт"))       # 6

```

---

## 5. Спеціальні (екрановані) символи

Іноді в рядок потрібно вставити службові команди, які неможливо просто надрукувати. Для цього використовується зворотний слеш `\`.

* `\n` — перехід на новий рядок.
* `\t` — табуляція (відступ, як клавіша Tab).
* `\"` або `\'` — дозволяє вставити лапку всередину аналогічних лапок.

```python
print("Рядок один\nРядок два") 
# Виведе:
# Рядок один
# Рядок два

print("Команда:\tПрогрес") # Виведе текст із великим відступом

print('Він сказав: \'Привіт\'') # Екранування одинарної лапки

```
