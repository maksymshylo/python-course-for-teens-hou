# 📖 Словники в Python: Тип даних `dict` (Dictionary)

**Словник (`dict`)** — це невпорядкована (починаючи з Python 3.7 — впорядкована за порядком додавання) колекція елементів, де дані зберігаються у вигляді пар **«ключ: значення»** (key: value).

На відміну від списків, де доступ до елементів здійснюється за порядковими індексами (`0, 1, 2...`), у словниках ви звертаєтеся до значень за їхніми унікальними **ключами** (наприклад, за словом, ID-номером чи кодом).

---

## 1. Створення словників

Словники створюються за допомогою **фігурних дужок `{}**`, а пари «ключ-значення» розділяються двокрапкою `:`.

```python
# Порожній словник
empty_dict = {}
# або за допомогою функції dict()
empty_dict_2 = dict()

# Словник з даними (профіль користувача)
user = {
    "username": "coder_neo",
    "email": "neo@matrix.io",
    "age": 25,
    "is_admin": True
}

# Ключами зазвичай є рядки або числа. 
# Значеннями може бути будь-який тип даних: числа, рядки, списки чи навіть інші словники.

```

---

## 2. Доступ до елементів словника

Зчитати значення зі словника можна двома основними способами: через квадратні дужки або через метод `.get()`.

### Спосіб 1: Квадратні дужки `[ключ]`

```python
user = {"name": "Олена", "age": 22}

print(user["name"])  # Виведе: Олена

# ⚠️ ПАСТКА: Якщо ключа не існує, програма зламається з помилкою KeyError!
# print(user["phone"]) # Помилка KeyError: 'phone'

```

### Спосіб 2: Метод `.get(ключ, альтернатива)`

Цей спосіб набагато безпечніший, оскільки не викликає помилки, якщо ключа немає.

```python
user = {"name": "Олена", "age": 22}

# Якщо ключа немає, поверне None (нічого)
print(user.get("phone"))  # Виведе: None

# Можна вказати значення за замовчуванням, яке повернеться замість помилки
print(user.get("phone", "Телефон не вказано"))  # Виведе: Телефон не вказано

```

---

## 3. Додавання, зміна та видалення елементів

Словники є **змінними (mutable)**, тому ви можете легко редагувати їхній вміст.

```python
car = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
}

# 1. Зміна значення (якщо ключ уже існує)
car["year"] = 2023 

# 2. Додавання нового елемента (якщо такого ключа ще не було)
car["color"] = "red"
print(car)  # {'brand': 'Ford', 'model': 'Mustang', 'year': 2023, 'color': 'red'}

# 3. Видалення елемента за допомогою del
del car["model"]

# 4. Видалення за допомогою .pop(ключ) — видаляє та повертає значення
deleted_year = car.pop("year")
print(f"Видалено рік: {deleted_year}") 
print(car)  # {'brand': 'Ford', 'color': 'red'}

```

---

## 4. Корисні методи для роботи зі словниками

Часто виникає потреба отримати окремо всі ключі або всі значення із бази даних словника.

```python
student = {"name": "Ігор", "course": 3, "major": "Computer Science"}

# 1. .keys() — повертає всі ключі
print(student.keys())    # dict_keys(['name', 'course', 'major'])

# 2. .values() — повертає всі значення
print(student.values())  # dict_values(['Ігор', 3, 'Computer Science'])

# 3. .items() — повертає пари (кортежі) ключ-значення (дуже корисно для циклів)
print(student.items())   # dict_items([('name', 'Ігор'), ('course', 3), ('major', 'Computer Science')])

# 4. len() — показує кількість пар у словнику
print(len(student))      # 3

# 5. Перевірка наявності ключа через оператор 'in'
print("name" in student)   # True
print("salary" in student) # False

```

## 🔍 Практичний приклад: Система інвентарю в грі

Подивимося, як словники допомагають структурувати складніші дані (наприклад, інвентар персонажа у грі), поєднуючи роботу зі списками, функцією `len()` та умовними операторами:

```python
# Словник описує стан персонажа
player = {
    "name": "Aragorn",
    "level": 12,
    "health": 85.5,
    "inventory": ["меч", "щит", "зілля здоров'я", "карта"] # значення-список
}

print(f"--- ⚔️ Профіль гравця {player['name']} ---")
print(f"Рівень: {player['level']}")
print(f"Здоров'я: {player['health']}%")

# Перевіряємо кількість предметів в інвентарі, який лежить у словнику
items_count = len(player["inventory"])
print(f"Предметів у торбі: {items_count}")

# Логіка використання предмета
if "зілля здоров'я" in player["inventory"]:
    print("✨ Використано зілля здоров'я! Здоров'я відновлено до 100%.")
    player["health"] = 100.0  # Змінюємо значення в словнику
    player["inventory"].remove("зілля здоров'я") # Видаляємо елемент із внутрішнього списку
else:
    print("❌ У вас немає лікувальних зіль!")

print(f"Оновлений стан гравця: {player}")

```
