# 🔒 Кортежі в Python: Тип даних `tuple`

**Кортеж (`tuple`)** — це впорядкована колекція елементів, яка дуже схожа на список (`list`), але з однією фундаментальною відмінністю: кортежі є **незмінними (immutable)**.

Це означає, що після того, як кортеж створено, ви не можете додати до нього нові елементи, видалити наявні або змінити їх порядок чи значення.

---

## 1. Створення кортежів

Кортеж створюється за допомогою **круглих дужок `()**`, а елементи всередині розділяються комами.

```python
# Порожній кортеж
empty_tuple = ()
# або за допомогою функції tuple()
empty_tuple_2 = tuple()

# Кортеж із даними (наприклад, географічні координати)
coordinates = (50.4501, 30.5234)

# Кортеж може містити елементи різних типів
person = ("Олексій", 30, "Київ", True)

# ⚠️ ПАСТКА: Якщо ви хочете створити кортеж з ОДНОГО елемента, обов'язково потрібно поставити кому після нього!
# Інакше Python подумає, що це просто математичні дужки.
not_a_tuple = (42)    # Тип: int
is_a_tuple = (42,)    # Тип: tuple

```

---

## 2. Індексація та зрізи кортежів

Оскільки кортеж є впорядкованою послідовністю, робота з індексами та зрізами тут абсолютно ідентична спискам (`list`) та рядкам (`str`). Індексація починається з `0`.

```python
fruits = ("яблуко", "банан", "апельсин", "груша")

print(fruits[0])   # "яблуко"
print(fruits[-1])  # "груша" (останній елемент)
print(fruits[1:3]) # ("банан", "апельсин") — повертає новий кортеж-зріз

```

---

## 3. Чому саме кортежі? (Головна відмінність від списків)

Навіщо потрібні кортежі, якщо є зручніші списки, які можна змінювати? Є три основні причини:

1. **Захист даних від випадкових змін:** Якщо ви маєте набір констант, які ніколи не повинні змінюватися під час роботи програми (наприклад, дні тижня, налаштування доступу, конфігурація сервера), кортеж гарантує, що жодна частина коду їх випадково не перезапише.
2. **Швидкість роботи:** Кортежі займають менше місця в оперативній пам'яті комп'яті та обробляються швидше, ніж списки.
3. **Використання в якості ключів словника:** Списки не можна використовувати як ключі у словниках (`dict`), бо вони змінювані. Оскільки кортежі незмінні, вони можуть слугувати ключами (наприклад, координати `(x, y)` як ключ для мапи).

```python
# Спроба змінити елемент кортежу призведе до помилки:
colors = ("червоний", "зелений", "синій")

# colors[0] = "жовтий"  
# ❌ Помилка TypeError: 'tuple' object does not support item assignment

```

## 4. Корисні операції та методи

Оскільки кортежі не можна модифікувати, у них немає таких методів, як `.append()`, `.pop()` чи `.remove()`. Проте з ними працюють інші стандартні інструменти:

```python
numbers = (10, 20, 30, 20, 40)

# 1. len() — повертає кількість елементів у кортежі
print(len(numbers))  # 5

# 2. .count(значення) — рахує, скільки разів елемент зустрічається в кортежі
print(numbers.count(20))  # 2

# 3. .index(значення) — повертає індекс першого знайденого елемента
print(numbers.index(30))  # 2

# 4. Оператор 'in' — перевірка наявності елемента
print(50 in numbers)  # False

# 5. Конкатенація (додавання) — створює НОВИЙ кортеж
more_numbers = numbers + (50, 60)
print(more_numbers)  # (10, 20, 30, 20, 40, 50, 60)

```

---

## 5. Разпакування кортежів (Tuple Unpacking)

Python дозволяє дуже елегантно присвоювати елементи кортежу окремим змінним за один крок. Ця фіча використовується постійно.

```python
# У нас є кортеж із даними про товар
product = ("Ноутбук", 25000, "В наявності")

# Распакування в окремі змінні
title, price, status = product

print(title)  # "Ноутбук"
print(price)  # 25000
print(status) # "В наявності"

# ⚠️ Кількість змінних ліворуч має ТОЧНО збігатися з кількістю елементів у кортежі, 
# інакше виникне помилка ValueError.

```
