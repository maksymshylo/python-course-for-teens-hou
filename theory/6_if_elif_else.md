# 🚦 Розгалуження в Python: Умовний оператор `if-elif-else`

Програми не завжди виконуються лінійно від початку до кінця. Часто коду потрібно «приймати рішення» залежно від певних умов. Для цього в Python використовується конструкція `if` (якщо), `elif` (якщо ще), та `else` (інакше).

---

## 1. Базова структура `if`

Найпростіший варіант — це коли дія виконується лише тоді, коли умова істинна (`True`). Якщо умова хибна (`False`), програма просто ігнорує цей блок коду.

> ⚠️ **КРИТИЧНО ВАЖЛИВО:** У Python відступи (зазвичай 4 пробіли або клавіша Tab) визначають, який саме код належить до блоку `if`. Якщо забути відступ, програма або працюватиме неправильно, або видасть помилку `IndentationError`. Також після кожної умови обов'язково ставиться **двокрапка `:**`.

```python
age = 20

if age >= 18:
    print("Ви повнолітній.")  # Цей рядок має відступ і виконається ТІЛЬКИ якщо age >= 18
    print("Доступ дозволено.") # Цей теж належить до блоку if

print("Цей текст виведеться у будь-якому випадку.") # Немає відступу — код поза if

```

---

## 2. Повна конструкція: `if-else` (Якщо — Інакше)

Використовується, коли у вас є два чітких варіанти розвитку подій: якщо умова виконується — робимо одне, якщо не виконується — робимо інше.

```python
money = 50
price = 60

if money >= price:
    print("Покупка успішна! Дякуємо.")
else:
    print("Недостатньо коштів на рахунку.") # Виконається, якщо умова в 'if' повернула False

```

---

## 3. Множинні умови: `if-elif-else`

Коли варіантів більше ніж два, використовується оператор `elif` (скорочення від *else if* — «інакше якщо»). Таких блоків `elif` можна додавати скільки завгодно. Python перевіряє їх по черзі зверху вниз і виконає **тільки перший блок, умова якого виявиться `True**`.

```python
score = 85

if score >= 90:
    print("Ваша оцінка: Відмінно (A)")
elif score >= 75:
    print("Ваша оцінка: Добре (B)")     # Виконається це, оскільки 85 >= 75
elif score >= 60:
    print("Ваша оцінка: Задовільно (C)")
else:
    print("Незадовільно. Потрібно перездати.") # Виконається, якщо ЖОДНА умова вище не підійшла

```

---

## 4. Складні умови (Логічні оператори)

Усередині `if` можна комбінувати кілька умов за допомогою вже знайомих операторів `and`, `or`, `not`.

```python
has_ticket = True
is_vip = False
has_heavy_luggage = True

# Приклад 1: Використання AND та OR
if (has_ticket or is_vip) and not has_heavy_luggage:
    print("Ласкаво просимо на борт літака!")
else:
    print("Посадка відхилена. Перевірте квиток або багаж.")

```

---

## 5. Тернарний оператор (Умова в один рядок)

Якщо потрібно просто записати у змінну одне з двох значень залежно від умови, 
розгортати `if-else` на 4 рядки не варто.

**Синтаксис:** `змінна = значення_якщо_True if умова else значення_якщо_False`

```python
a = 17
# Запис в один рядок
is_adult = True if a >= 18 else False

```

---

## 6. Вкладені умовні оператори

Ви можете перевіряти нові умови всередині вже наявних блоків `if` чи `else`. Головне — дотримуватися додаткових відступів.

```python
username = "admin"
password = "123"

if username == "admin":
    print("Логін правильний.")
    # Вкладена перевірка
    if password == "12345":
        print("Вхід успішний! Вітаємо, адмін.")
    else:
        print("Пароль невірний.")
else:
    print("Користувача не знайдено.")

```
