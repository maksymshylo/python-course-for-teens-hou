# 📖 Базові оператори у Python

Python має багатий набір операторів для виконання різних завдань: 
від простої арифметики до складної логіки та маніпуляцій з бітами.

## 1. Арифметичні оператори

Використовуються для виконання стандартних математичних обчислень.

```python
a = 10
b = 3

print("--- Арифметичні оператори ---")
print(f"Додавання (a + b): {a + b}")          # 13
print(f"Віднімання (a - b): {a - b}")         # 7
print(f"Множення (a * b): {a * b}")           # 30
print(f"Ділення (a / b): {a / b}")            # 3.3333333333333335 (у Python 3 завжди повертає тип float)

# Цілочисельні оператори
print(f"Ділення без остачі (a // b): {a // b}") # 3 (повертає цілу частину від ділення)
print(f"Остача від ділення (a % b): {a % b}")   # 1 (корисно для перевірки на парність: x % 2 == 0)
print(f"Піднесення до степеня (a ** b): {a ** b}") # 1000 (10 в кубі)
```

---

## 2. Оператори порівняння

Ці оператори порівнюють значення між собою та завжди повертають логічне значення (`True` або `False`).

```python
print("\n--- Оператори порівняння ---")        # Символ \n означає вивід з нового рядка
print(f"Рівність (a == b): {a == b}")          # False
print(f"Нерівність (a != b): {a != b}")        # True
print(f"Більше (a > b): {a > b}")              # True
print(f"Менше (a < b): {a < b}")              # False
print(f"Більше або рівно (a >= b): {a >= b}")   # True
print(f"Менше або рівно (a <= b): {a <= b}")   # False

```

---

## 3. Логічні оператори

Використовуються для комбінування кількох умов. Найчастіше застосовуються в інструкціях `if`, `while` тощо.

* **`and` (Логічне І):** істинне (`True`), лише якщо **обидва** операнди істинні.
* **`or` (Логічне АБО):** істинне, якщо **хоча б один** з операндів істинний.
* **`not` (Логічне НЕ):** інвертує значення (перетворює `True` на `False` і навпаки).

```python
print("\n--- Логічні оператори ---")
x = True
y = False

print(f"Логічне 'І' (x and y): {x and y}")      # False (обидва мають бути True)
print(f"Логічне 'АБО' (x or y): {x or y}")      # True (хоча б один має бути True)
print(f"Логічне 'НЕ' (not x): {not x}")         # False (інверсія)

```

## 4. Оператори присвоєння та скороченого запису

Використовуються для запису результату обчислень у змінну. Скорочені оператори дозволяють змінити значення змінної відносно її поточного стану без повторного написання її імені.

```python
print("\n--- Оператори присвоєння ---")
c = 5   # Звичайне присвоєння

c += 2  # Еквівалентно: c = c + 2
print(f"Скорочене додавання (c += 2): {c}")   # 7

c *= 3  # Еквівалентно: c = c * 3
print(f"Скорочене множення (c *= 3): {c}")   # 21

c -= 1  # Еквівалентно: c = c - 1
print(f"Скорочене віднімання (c -= 1): {c}") # 20

```
