У Python **усе є об'єктом**, тому кожен тип даних має додаткову 
"вагу" — метадані (посилання на тип, лічильник посилань тощо).
Через це навіть порожній об'єкт займає певну кількість байтів у пам'яті.
Нижче наведено таблицю розмірів основних типів даних у Python (для 64-бітної системи).

---

### 📊 Таблиця розмірів типів даних у Python

| Тип даних         | Назва в Python | Базова "вага" (порожній об'єкт) | Як збільшується розмір?                                         | Приклад (вага в байтах)                                                |
|:------------------|:---------------|:--------------------------------|:----------------------------------------------------------------|:-----------------------------------------------------------------------|
| **Ціле число**    | `int`          | **28 байтів** (для числа `0`)   | +4 байти на кожне перевищення ліміту 2³⁰                        | `sys.getsizeof(10)` ➡️ **28 Б**<br>`sys.getsizeof(10**20)` ➡️ **36 Б** |
| **Дробове число** | `float`        | **24 байти**                    | Завжди фіксований (64 біти на саме число + метадані)            | `sys.getsizeof(3.14)` ➡️ **24 Б**                                      |
| **Логічний**      | `bool`         | **28 байтів**                   | Фіксований (насправді `bool` — це підтип `int`)                 | `sys.getsizeof(True)` ➡️ **28 Б**                                      |
| **Рядок**         | `str`          | **49 байтів** (порожній `""`)   | +1 байт за кожен ASCII-символ (або +2/+4 для емодзі/ієрогліфів) | `sys.getsizeof("Hi")` ➡️ **51 Б**                                      |
| **Список**        | `list`         | **56 байтів** (порожній `[]`)   | +8 байтів за кожне нове посилання на елемент                    | `sys.getsizeof([1, 2])` ➡️ **72 Б**                                    |
| **Кортеж**        | `tuple`        | **40 байтів** (порожній `()`)   | +8 байтів за кожен елемент (але економніший за список)          | `sys.getsizeof((1, 2))` ➡️ **56 Б**                                    |
| **Словник**       | `dict`         | **64 байти** (порожній `{}`)    | Збільшується порціями (хеш-таблиця розширюється при заповненні) | `sys.getsizeof({"a": 1})` ➡️ **64 Б**                                  |

---

### 🕵️‍♂️ Як перевірити це самостійно в коді?

Проведіть експеримент і "зважте" будь-яку змінну за допомогою вбудованого модуля `sys` та функції `getsizeof()`:

```python
import sys

# Важимо прості типи
print(sys.getsizeof(0))         # Виведе: 28 (байтів)
print(sys.getsizeof(3.14))      # Виведе: 24
print(sys.getsizeof(""))        # Виведе: 49 (базовий розмір рядка)
print(sys.getsizeof("A"))       # Виведе: 50 (49 базових + 1 байт на літеру 'A')

# Важимо колекції
print(sys.getsizeof([]))        # Виведе: 56
print(sys.getsizeof([1, 2, 3])) # Виведе: 80 (56 + 3 * 8 байтів)
```

### 💡 Важливо
Коли ми кладемо елементи у список (`list`) чи словник (`dict`), базовий розмір збільшується на **8 байтів** за кожен 
елемент не тому, що сам елемент там лежить. Список у Python — це просто "коробка з указками" (посиланнями). Кожна указка 
(адреса в пам'яті) на 64-бітній системі займає рівно 8 байтів (64 біти).
