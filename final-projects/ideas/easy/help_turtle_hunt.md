# 🏆 Фінальний проєкт: Гра «Черепашка-мисливець»

### 📝 Опис проєкту

На екрані знаходяться дві черепашки:

* 🟢 **Втікач** — рухається випадково по полю.
* 🔴 **Мисливець** — керується гравцем за допомогою клавіш.

Завдання гравця — наздогнати та зловити втікача.

Коли відстань між черепашками стає дуже маленькою, гра завершується повідомленням:

**«Спіймано! Перемога!» 🎉**

---

## 🛠️ Що потрібно для гри

* Модулі `turtle` та `random`.
* Функції для керування клавішами.
* Цикл `while`.
* Умовні оператори `if`.
* Методи роботи з координатами (`xcor()`, `ycor()`, `distance()`).
* Створення кількох об'єктів-черепашок.

---

## 🧱 Етапи створення проєкту

### 1. Налаштування ігрового поля

Створити вікно гри із зеленим або блакитним фоном.

### 2. Створення персонажів

Створити дві черепашки:

* 🔴 Мисливець
* 🟢 Втікач

Розташувати їх у різних місцях екрана.

### 3. Керування мисливцем

Гравець керує червоною черепашкою:

* ↑ — рух вперед
* ← — поворот вліво
* → — поворот вправо

### 4. Рух втікача

У кожній ітерації циклу:

* повернути на випадковий кут;
* пройти випадкову відстань.

```python
runner.left(random.randint(-30, 30))
runner.forward(random.randint(5, 15))
```

### 5. Перевірка перемоги

Постійно обчислювати відстань між черепашками.

```python
distance = hunter.distance(runner)

if distance < 20:
    print("Спіймано!")
```

### 6. Завершення гри

Вивести великий напис:

**«Мисливець переміг!»**

---

## 📄 Шаблон проєкту

```python
import turtle
import random

# Екран
screen = turtle.Screen()
screen.title("Черепашка-мисливець")
screen.bgcolor("lightblue")
screen.setup(800, 600)

# Мисливець
hunter = turtle.Turtle()
hunter.shape("turtle")
hunter.color("red")

# Втікач
runner = turtle.Turtle()
runner.shape("turtle")
runner.color("green")
runner.penup()
runner.goto(200, 100)
```

## 🧠 Додатковий функціонал

- Рівні складності

    Легкий:
    
    ```python
    runner.forward(random.randint(5, 10))
    ```

    Складний:
    
    ```python
    runner.forward(random.randint(10, 20))
    ```

- Порахувати, за скільки секунд гравець спіймав втікача.

- Очки

    Після кожного спіймання:
    
    ```python
    score += 1
    ```
    і втікач з'являється в новому місці.

- Перешкоди

    Намалювати камені або дерева, через які не можна проходити.

- Телепортація

    Іноді втікач випадково переноситься в іншу точку поля.
