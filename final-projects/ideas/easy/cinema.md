# 🎬 Фінальний проєкт: Квиткова каса кінотеатру

## 📝 Опис проєкту

Тобі потрібно створити просту програму для купівлі квитків у кіно через консоль. 
Усі дані (користувачі, фільми та місця в залі) зберігаються у звичайних списках прямо в коді.

---

## 📂 Як зберігаються дані (Змінні в коді)

Замість файлів ми створюємо три прості змінні на самому початку програми:

```python
# Список користувачів (за замовчуванням є один адмін)
users = [{"login": "admin", "password": "123"}]

# Список доступних фільмів
movies = [
    {"id": 1, "title": "Месники", "time": "19:00", "price": 150},
    {"id": 2, "title": "Гаррі Поттер", "time": "21:30", "price": 120}
]

# Карта залу (матриця: 3 ряди по 5 місць). 0 - вільно, 1 - зайнято
hall = [
    [0, 0, 0, 0, 0],  # Ряд 1
    [0, 0, 1, 0, 0],  # Ряд 2 (тут третє місце вже зайняте)
    [0, 0, 0, 0, 0]   # Ряд 3
]
```

---

## 🚀 Покрокова розробка (Етапи)

### 🔐 Етап 1: Вхід або Реєстрація

При запуску програма пропонує вибір: **1. Увійти | 2. Зареєструватися**.

* **Реєстрація:** Користувач придумує логін та пароль. Програма перевіряє, щоб пароль був довшим за 4 символи, і додає новий словник `{"login": логін, "password": пароль}` до нашого списку `users` за допомогою `.append()`.
* **Вхід:** Програма перевіряє, чи є введені логін та пароль у списку `users`. Якщо все правильно — пускає далі.

### 📅 Етап 2: Вибір фільму

На екран виводиться список фільмів (можна просто циклом `for` перебрати список `movies`). Користувач вводить `ID` фільму, на який хоче купити квиток.

### 💺 Етап 3: Показ залу та вибір місця

Програма виводить на екран карту залу за допомогою циклів.

* Замість цифр `0` показуй порожні крісла `[ ]`, а замість `1` — хрестики `[X]`.
* **Вибір:** Користувач вводить номер ряду та номер місця.
* **Перевірка:** Програма перевіряє: якщо в списку `hall[ряд - 1][місце - 1] == 1`, то каже: *"Ой, місце вже зайняте!"*. Якщо там `0`, то змінює його на `1`.

### 🧾 Етап 4: Текстовий чек

Програма виводить фінальний красивий квиток для користувача:

```text
====================================
🎟️ ЕЛЕКТРОННИЙ КВИТОК КІНОТЕАТРУ 🎟️
====================================
👤 Глядач: [Ім'я користувача]
🎬 Фільм: Месники (19:00)
🍿 Місце: Ряд 2, Крісло 4
💳 До сплати: 150 грн
====================================

```
