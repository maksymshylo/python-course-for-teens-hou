# Курс Python та програмування для підлітків 🐍

Курс програмування на Python українською мовою,
розроблений для підлітків за підтримки організації House of Ukraine, Sweden.

## 📋 Про курс

Волонтерський курс Python, 
який охоплює фундаментальні концепції програмування та розробки.

## 📚 Зміст курсу

### Уроки

**1. Вступ**

Презентація курсу.
Встановлення середовища розробки.
Запуск міні ігор.

**2. Типи даних та логіка**

Типи даних: `int`, `float`, `str`, `bool`.
Базові математичні оператори. 
Логічні оператори `and`, `or`, `not`. 
Поняття ідентичності об'єктів та оператор `is`.

**3. Розгалуження та прийняття рішень**

Умовні конструкції `if`, `elif`, `else`. Вкладені умови. Пріоритети виконання логічних виразів.

**4.Структури даних (Колекції)**

Списки (`list`), словники (`dict`) та кортежі (`tuple`). Головні методи для роботи з ними. 
Мутабельність (змінність) списків та словників проти незмінності кортежів.

**5. Цикли та range**

Цикли `for` та `while`. Робота з генератором `range()`. Керування циклами за допомогою `break` та `continue`. 
Пастки нескінченних циклів та зсуву індексів при модифікації колекцій.

**6. Функції**

Створення власних функцій через `def`.
Аргументи та параметри (позиційні та іменовані).
Повернення результату за допомогою `return`.
Області видимості змінних (глобальні та локальні, правило `LEGB`).

**7. Інструменти розробника (Git & GitHub)**

Що таке система контролю версій. Встановлення Git.
Основні команди в терміналі: `git init`, `add`, `commit`, `status`, `log`.
Створення репозиторію на GitHub та завантаження туди свого коду (`git push`).

## 🌐 Онлайн-курси та документація

* **[Prometheus — «Програмування для всіх: основи Python»](https://prometheus.org.ua/prometheus-free/python-fundamentals-for-everyone/)**
    * *Опис:* Популярний безкоштовний базовий курс від провідної української платформи масових онлайн-курсів. 
    Ідеально підходить для повного старту з нуля.
* **[Офіційна документація Python (Українська версія)](https://docs.python.org/uk/3/tutorial/index.html)**
    * *Опис:* Офіційний практичний посібник (Tutorial) від Python Software Foundation, повністю перекладений українською
    мовою. Головне джерело актуальних стандартів мови.
* **[LearnPython.org (Українською)](https://www.learnpython.org/uk/)**
    * *Опис:* Безкоштовний інтерактивний онлайн-підручник. Дозволяє вивчати синтаксис та відразу виконувати практичні 
    вправи безпосередньо у браузері без необхідності встановлення додаткового ПЗ.

## 📚 Книги для вивчення Python

* **«Learning Python» (5th Edition)**
    * *Автор:* Mark Lutz
    * *Опис:* Справжня фундаментальна праця (часто називають «Біблією Python») для максимально глибокого розуміння 
      структури мови, об'єктно-орієнтованого програмування та внутрішніх механізмів роботи інтерпретатора.
* **«Python Crash Course»**
    * *Автор:* Eric Matthes
    * *Опис:* Один із найкращих світових бестселерів для практичного та швидкого занурення. Книга розділена на дві 
      частини: чітка теорія та створення реальних проєктів (ігри, візуалізація даних, вебдодатки на Django).
* **«Coding Python for Kids: Learn how to code with 50 awesome games and activities»**
    * *Автор:* Adrienne B. Tacke
    * *Опис:* Чудове барвисте видання, орієнтоване на дітей та абсолютних новачків. Базові концепції (цикли, змінні, 
      функції) пояснюються простою мовою через розробку 50 цікавих міні-ігор.
