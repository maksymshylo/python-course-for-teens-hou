# Курс Python та програмування для підлітків 🐍

Курс програмування на Python українською мовою,
розроблений для підлітків за підтримки організації House of Ukraine, Sweden.

## 📋 Про курс

Волонтерський курс Python, 
який охоплює фундаментальні концепції програмування та розробки.

## 📚 Зміст курсу

### Уроки

Курс включає:

1. **Урок 1** - Презентація курсу. Встановлення програм. Змінні. `True`, `False`, `is`.
2. **Урок 2** - Базові оператори. `Int`, `float`, `strings` та синтаксис Python.
3. **Урок 3** - Списки, словники, кортежі та функції до них.
4. **Урок 4** - Цикли `for` та `while`. Діапазон range.
5. **Урок 5** - Конструкції розгалуження `if`, `elif`, `else`. Логічні оператори (`and`, `or`, `not`) та пріоритети їх обчислення.
6. **Урок 6** - Функції (`def`). Аргументи та параметри. Повернення значень через `return`. Області видимості змінних.
7. **Урок 7** - Робота з текстом та файлами. Читання та запис даних (`open`, `with open`).
8. **Урок 8** - Обробка помилок та винятків (`try`, `except`, `finally`, `else`).
9. **Урок 9** - Модулі та бібліотеки (`math`, `random`, `datetime`, `os`, `sys`). Встановлення сторонніх пакетів через `pip`.
10. **Урок 10** - Git та Github. Основні команди.
11. **Урок 11** - Повторення вивченого.
12. **Урок 12** - Фінальний проєкт.

## 🌐 Онлайн-курси та документація

* **[Prometheus — «Програмування для всіх: основи Python»](https://prometheus.org.ua/prometheus-free/python-fundamentals-for-everyone/)**
    * *Опис:* Популярний безкоштовний базовий курс від провідної української платформи масових онлайн-курсів. Ідеально підходить для повного старту з нуля.
* **[Офіційна документація Python (Українська версія)](https://docs.python.org/uk/3/tutorial/index.html)**
    * *Опис:* Офіційний практичний посібник (Tutorial) від Python Software Foundation, повністю перекладений українською мовою. Головне джерело актуальних стандартів мови.
* **[LearnPython.org (Українською)](https://www.learnpython.org/uk/)**
    * *Опис:* Безкоштовний інтерактивний онлайн-підручник. Дозволяє вивчати синтаксис та відразу виконувати практичні вправи безпосередньо у браузері без необхідності встановлення додаткового ПЗ.

## 📚 Книги для вивчення Python

* **«Learning Python» (5th Edition)**
    * *Автор:* Mark Lutz
    * *Опис:* Справжня фундаментальна праця (часто називають «Біблією Python») для максимально глибокого розуміння структури мови, об'єктно-орієнтованого програмування та внутрішніх механізмів роботи інтерпретатора.
* **«Python Crash Course»**
    * *Автор:* Eric Matthes
    * *Опис:* Один із найкращих світових бестселерів для практичного та швидкого занурення. Книга розділена на дві частини: чітка теорія та створення реальних проєктів (ігри, візуалізація даних, вебдодатки на Django).
* **«Coding Python for Kids: Learn how to code with 50 awesome games and activities»**
    * *Автор:* Adrienne B. Tacke
    * *Опис:* Чудове барвисте видання, орієнтоване на дітей та абсолютних новачків. Базові концепції (цикли, змінні, функції) пояснюються простою мовою через розробку 50 цікавих міні-ігор.
