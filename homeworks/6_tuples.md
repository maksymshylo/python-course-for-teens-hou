## 🧠 Завдання 4: Цікавинка (Обмін змінними)

В інших мовах програмування, щоб поміняти значення двох змінних місцями, треба створювати третю (тимчасову) змінну. В Python це робиться в один рядок завдяки кортежам.

Що виведе цей код? Спробуйте здогадатися, як Python робить це "за лаштунками".

```python
a = 5
b = 10

a, b = b, a

print("a =", a)
print("b =", b)

```

Коли ми пишемо `b, a` справа від знаку `=`, Python спочатку автоматично пакує ці значення у прихований кортеж `(10, 5)`. А потім, за допомогою розпакування, присвоює їх змінним `a` та `b` зліва направо!

## 🎩 Завдання 5: Головна пастка "Незмінності" (Мутабельний всередині імутабельного)

Що виведе цей код? Спробуйте вгадати, чи дозволить Python таку маніпуляцію.

```python
secret_data = ("Олексій", [20, 30, 40])

secret_data[1].append(50)

print(secret_data)

```

Сам кортеж змінити не можна — його "коробки" (посилання на об'єкти) заблоковані. Але в другій коробці лежить **список** (`list`), а список є змінним! Ми не міняли сам список на інший об'єкт, ми просто додали в нього елемент. Тому Python це дозволить. Кортеж лишився тим самим, але його вміст всередині списку змінився!
