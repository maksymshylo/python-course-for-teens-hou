## 🧠 Завдання 4: Цікавинка (Що може бути ключем?)

В Python ключем словника може бути лише **незмінний (immutable)** тип даних.
Які з цих рядків коду викличуть критичну помилку `TypeError: unhashable type`, а які спрацюють ідеально? Спробуйте вгадати, а потім перевірте в консолі.

```python
# Варіант А
bad_dict = { [1, 2]: "це список" }

# Варіант Б
good_dict = { (1, 2): "це кортеж" }

```

Списки (`list`) можна змінювати (вони mutable), тому комп'ютер не може гарантувати, що їхня "адреса" (хеш) не зміниться. Через це списки **не можуть** бути ключами. А от кортежі (`tuple`) — незмінні, тому вони чудово підходять на роль ключів!

## Завдання 7: Пастка "Копіювання вкладених словників"

Новачок вирішив скопіювати словник із даними компанії, щоб змінити назву філіалу, не чіпаючи оригінал:

```python
company_1 = {
    "name": "TechCorp",
    "location": {"city": "Kyiv", "street": "Main St"}
}

company_2 = company_1.copy()  # Поверхневе копіювання (shallow copy)
company_2["location"]["city"] = "Lviv"

print("Компанія 1:", company_1["location"]["city"])
print("Компанія 2:", company_2["location"]["city"])

```

Запустіть цей код. Ви побачите, що місто змінилося в **обох** словниках!

* Що таке поверхнева копія (`shallow copy`)?
* Який модуль та яку функцію потрібно імпортувати, щоб зробити повну, глибоку копію (`deepcopy`), яка скопіює абсолютно всі вкладені рівні?
