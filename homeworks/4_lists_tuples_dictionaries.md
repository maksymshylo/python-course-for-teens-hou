### 🧠 Завдання 4: Неочевидний трюк зі списками та словниками ⭐️

Подивіться на цей код і спробуйте передбачити, що виведеться на екран:

```python
list_a = [1, 2, 3]
list_b = list_a

list_b.append(4)

print("Список A:", list_a)
print("Список B:", list_b)
```

<details>
<summary>💡 Натисни сюди, щоб побачити підказку</summary>

Списки та словники в Python є мутабельними (змінними).
Коли ви пишете `list_b = list_a`, Python не копіює сам список, а просто створює нове посилання, яке веде на той самий 
об'єкт у пам'яті.
Вони мають однакову адресу (`id()`), тому зміни через будь-яку змінну міняють один єдиний об'єкт.

</details>

### 🧩 Завдання 5: Пастка "Хитрого Кортежу" (Неможливе можливо?)
Ми вчили, що кортежі (`tuple`) — незмінні. Але подивіться на цей код:

1. Спробуйте вгадати: викличе цей код помилку чи ні? Що з'явиться на екрані?
2. Запустіть код та перевірте себе.

```python
# Створюємо кортеж, де другий елемент — це список
crazy_tuple = (1, [10, 20], 3)

# Спробуємо змінити список ВСЕРЕДИНІ кортежу
crazy_tuple[1].append(30)

print(crazy_tuple)
```

**Запитання:**
- Чому Python дозволив це зробити?
- Чи змінилася адреса самого списку від того, що ми додали всередину число?.

<details>
<summary>💡 Натисни сюди, щоб побачити підказку</summary>

Кортеж залишився незмінним — він як тримав адресу списку, так і тримає. 
А от сам список за цією адресою — змінний (_**mutable**_), тому його вміст змінився. 
Python перевіряє лише незмінність `коробок` у кортежі, але не того, що всередині цих коробок.

</details>

###  🧩 Завдання 6: "Зникаючий" елемент (Множення списків)
Уявіть, що ви хочете створити таблицю (матрицю) розміром 3х3, заповнену нулями.

Запустіть код

```python
# Швидкий спосіб створити список із трьох нулів: [0, 0, 0]
row = [0, 0, 0]

# Робимо матрицю, повторюючи рядок 3 рази
matrix = [row] * 3
print("Початкова матриця:", matrix)

# Тепер міняємо всього ОДИН елемент у першому рядку
matrix[0][0] = 99
print("Матриця після зміни:", matrix)
```

**Запитання:**
- Чому дев'ятки з'явилися в першому стовпчику кожного рядка, хоча ми міняли тільки matrix[0][0]?


<details>
<summary>💡 Натисни сюди, щоб побачити підказку</summary>

Оператор * 3 не скопіював список row три рази. Він просто створив список із трьох посилань, які ведуть на один і той 
самий рядок у пам'яті. Змінюючи один — міняєш усі.

</details>

### 🧩 Завдання 7: Словник з "сюрпризом"
У Python ключами словника можуть бути лише незмінні об'єкти (числа, рядки, кортежі). Списки бути ключами не можуть.

Перевірте, що виведе цей код:

```python
secret_dict = {}

key1 = (1, 2)
secret_dict[key1] = "Успіх!"

# А тепер спробуємо таке:
key2 = (1, [2, 3])
secret_dict[key2] = "А тут що буде?" 
```

**Запитання:**
- Яку помилку (TypeError) ви отримали? 
- Чому один кортеж зміг стати ключем, а інший — ні?


<details>
<summary>💡 Натисни сюди, щоб побачити підказку</summary>

Ключ словника має бути hashable (мати незмінний цифровий відбиток). 
Якщо всередині кортежу з'являється мутабельний список, весь кортеж втрачає статус "надійного" і словник його відкидає.

</details>
