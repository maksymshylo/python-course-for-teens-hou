### 🔍 Завдання 2: Знайди що не так

Користувач написав такий код, щоб порахувати суму двох чисел:

```python
num1 = input("Введіть перше число: ")
num2 = input("Введіть друге число: ")

print("Сума чисел дорівнює:", num1 + num2)
```

**Запитання**:

- Що виведе цей код і чому?
- Як виправити помилку?
