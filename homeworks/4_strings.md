## 🧩 Завдання 2: `==` проти `is` для рядків (Інтернування)

У Python є секрет: він намагається економити пам'ять і оптимізувати роботу з текстом за
допомогою **інтернування рядків** (string interning).
Відкрийте **інтерактивну консоль Python** (термінал) і виконайте код **покроково**:

```python
# Крок 1: Короткі прості рядки
s1 = "hello"
s2 = "hello"

print(s1 == s2)  # Що виведе? (True чи False)
print(s1 is s2)  # Що виведе? (True чи False)

# Крок 2: Динамічно створені рядки (через input або runtime-операції)
s3 = "hello world!"
s4 = "".join(["hello", " ", "world!"])

print(s3 == s4)  # Що виведе?
print(s3 is s4)  # Що виведе?

```

**Запитання:**

* Що саме порівнює оператор `==` у рядках, а що — оператор `is`?
* Чому в Кроці 2 оператор `is` повернув `False`, хоча текст в обох змінних абсолютно однаковий?

## 🧠 Завдання 4: Цікавинка (Множення тексту?)

Що виведе Python, якщо запустити цей код?
Спробуйте здогадатися без комп'ютера, а потім перевірте себе:

```python
print("Ні" + "ні" * 3)
print(len("🧑‍💻"))  # Будьте уважні з емодзі!

```

* Оператор `*` має вищий пріоритет, ніж `+`, тому спочатку виконається множення рядка.
* Емодзі в Python іноді складаються з кількох символів Unicode (юнікод-сурогатів або комбінацій), тому функція `len()` може здивувати результатом!
