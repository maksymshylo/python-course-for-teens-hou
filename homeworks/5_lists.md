## 🧠 Завдання 4: Цікавинка (Множення списків)

Що виведе Python, якщо запустити цей код? Спробуйте здогадатися, а потім перевірте в консолі:

```python
matrix = [[0]] * 3
print("Матриця до змін:", matrix)

matrix[0][0] = 1
print("Матриця після змін:", matrix)

```

Коли ми множимо список через `* 3`, Python не створює 3 окремі внутрішні списки. Він створює 3 **посилання** на один і той самий список `[0]` у пам'яті. Змінюючи елемент через одне посилання — ми бачимо зміни в усіх трьох!

## 🎩 Завдання 5: "Сортування з руйнуванням"

Що виведе цей код на екран? Спробуйте вгадати без комп'ютера.

```python
numbers = [5, 2, 9, 1]

print(numbers.sort())
print(sorted(numbers))
print(numbers)

```

* Метод `.sort()` сортує список **на місці** (мутує оригінал) і нічого не повертає (тобто результат його роботи — `None`).
* Функція `sorted()` не чіпає оригінальний список, а створює і повертає **новий** відсортований список.
