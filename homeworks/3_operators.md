## 🎩 Завдання 5: "Математичний обман"
Що виведе цей код? Спробуйте вгадати без комп'ютера.

```python
print(3 > 2 > 1)
print(1 < 2 < 1)
print(False == False == False)
```

<details>
<summary>💡 Натисни сюди, щоб побачити підказку</summary>

* **Дія `=` (присвоювання):** Завжди **справа наліво** `(⬅️)`. Спочатку дізнаємося значення, потім даємо йому ім'я.
* **Математика та порівняння (`+`, `-`, `==`, `>`):** Завжди **зліва направо** `(➡️)` з урахуванням пріоритетів 
(як у школі: спочатку множення, потім додавання).

</details>

## Завдання 7: Пастка "Хибного порядку"
Новачок написав систему виставлення оцінок для університету. На його думку, логіка працює ідеально:

Запустіть цей код без змін. Що вивелося на екран для студента, який набрав 85 балів? 
Чи справедлива це оцінка?

```python
score = 85

if score >= 60:
    print("Оцінка: Задовільно")
elif score >= 75:
    print("Оцінка: Добре")
elif score >= 90:
    print("Оцінка: Відмінно")
else:
    print("Оцінка: Незадовільно")
```

**Запитання:**
- Чому Python обірвав перевірку на першому ж `if` і не пішов дивитися далі? 
- Як працює конструкція `if-elif-else`, коли знаходить першу істинну умову (`True`)?

**Виправлення:**
Змініть порядок умов або самі умови так, щоб програма працювала абсолютно правильно для будь-якої кількості балів 
(наприклад: 95 — відмінно, 80 — добре, 65 — задовільно, 50 — незадовільно).
